# Nova Tools Forge — brand

The emblem: a gold four-pointed star (the *nova*) rising from a lavender anvil (the *forge*),
on deep navy-purple.

| File | Use | Spec |
|---|---|---|
| `emblem.png` | **the source** — everything else is rendered from it | 1254×1254, opaque |
| `avatar-1024.png` | GitHub organisation picture | 1024×1024 PNG, ≤ 1 MB |
| `play-icon-512.png` | Google Play developer page icon | 512×512, 24-bit PNG without alpha, ≤ 1 MB |
| `play-header.jpg` | Google Play developer page header | 4096×2304 JPEG, ≤ 1 MB; the emblem centred on its own ground, edges feathered |
| `render.mjs` | renders the three from the source, and checks size, alpha and file size | `npm i --no-save sharp` here, then `node render.mjs` |

Colours: ground `#110B25` (sampled from the emblem's border), gold `#F7C948` / `#FFE08A`,
lavender `#A79FC7` — the same family as the Routine Champs icon.

## Provenance

Generated by the owner of Nova Tools Forge with ChatGPT (personal account), 2026-10-30, from
a prompt describing a flat star-over-anvil mark; chosen over hand-drawn SVG variants because
the faceted anvil and the glow read better. OpenAI's terms assign the output to the user and
allow commercial use. No logos, characters or third-party marks in it.

If the emblem changes: replace `emblem.png`, run `render.mjs`, upload the outputs again.
